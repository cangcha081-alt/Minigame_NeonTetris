## 并行关系与接口冻结

1. T02 后，T03 与 T05 可并行；T04 依赖 T03。T06 等待 T03/T04/T05 合并核验，不能多 Agent 同时修改 Engine。
2. T01 后 T08 可独立并行；测试夹具/测试向量设计可在模块实现前独立进行，但不得用尚不存在的实现结果写通过报告。
3. T07 与 T08 完成并冻结 Batch/Settings 接口后，T12 音频可与 T09/T10 界面链并行。音频阶段独立门槛先完成，整体验收仍等实际 UI 集成。
4. T10 后 T11 视觉可与尚未完成的 T12 音频并行；共同消费协议，不能互相调用或各自修改事件名。
5. UI 审查、核心算法审查、测试方案和音频资源审查可独立执行；主 Agent 统一快照、事件、时间、生命周期契约，逐条核验建议。
6. 每个并行任务限定文件所有权。改接口先更新契约并通知依赖任务；集成后运行相关检查，不以子 Agent “已完成”替代验证。
