## 本轮整理与缺陷处理

- 核对目录、模块导入、静态路径和 Node 依赖配置。保留视觉验收页和真实整合夹具，两页仍用于复核。
- 原背景照片的分发授权无法核实。改用项目原创 SVG 夜景，确认运行端没有照片引用后，移除工作区中的照片副本。原始素材与历史记录仍可追溯。见 [资源来源](../assets/ASSET_SOURCES.md)。
- 删除无调用的 `closeSettings()` 和两处无匹配的 CSS 类规则（`rule-label`、`landing-mark`）。保留供辅助技术读取的键位说明。
- 浏览器发现从运行中的棋盘移出焦点时，暂停界面会抢焦点。回归用例先复现自动暂停聚焦「继续」的失败。修复后自动暂停保留新控件的焦点，手动暂停仍聚焦「继续」。实测 Shift+Tab 到设置，Enter 打开，游戏维持暂停。
- 更新 README、项目规则、项目上下文、决策、协作记录、视觉规范和测试方案。阶段报告及历史测试计数按当时结果保留。

## 如何复现

1. 解压提交 ZIP，进入包含 `package.json` 的目录。用 Node.js 24+ 执行 `npm run dev`，浏览器访问 [本地入口](http://127.0.0.1:5173/)。
2. 在项目根目录执行 `npm test`。Windows PowerShell 可使用 `npm.cmd test`。全量测试会使用临时回环端口及临时目录链接。
3. 打开 [整合验收页](http://127.0.0.1:5173/assets/integration-review.html)，选「四消升级初局」或「结束前初局」，开始后按 Space。诊断可复查相应事件和资源状态。
4. 打开 [视觉验收页](http://127.0.0.1:5173/assets/visual-review.html)，展开底部工具，检查七色、暂停、结束和三种动效模式。

提交包包含 82 个项目文件。解压后逐文件对比内容，49 个 JS/MJS 通过语法检查。28 个源模块的 49 条相对导入无缺失或循环。运行资源检查确认原照片路径返回 404。Git 元数据与本地调试记录位于工作区，提交包仅包含可复现项目文件。

## 已知限制及未实现范围

- 当前是桌面键盘游戏，纯触屏没有完整局内操作。短窄屏需要滚动。浏览器节流或长帧会触发保护性暂停。
- 尚未量化真实设备音频输出峰值或跨浏览器持续帧性能。色弱、屏幕阅读器和闪光阈值也没有专项实测。
- 只持久化最高分与偏好，无棋局续玩。地域关卡、地图解锁、复杂任务、道具、Boss、多人联机和复杂成就均在课程范围之外。
