# NEON TETRIS · 游戏规则和操作说明

版本 0.2 · 2026-11-06 · 已确认 PRD 的规则基线。第三阶段统一状态名 RUNNING，旋转数据与算法见 ALGORITHMS.md；确认规则不等于实现或测试通过。

## 一、棋盘、方块与坐标

1. 可见棋盘为 10×20。列 x=0～9，从左至右；行 y=0～19，从上至下。
2. 额外保留两行隐藏生成区 y=-2、-1，只用于出生、旋转与顶部判定，不显示为额外棋盘行。超出左右、底部或隐藏区上边界的格子不可占用。
3. 七种方块 I、O、T、S、Z、J、L，每块四格。活动块与固定棋盘分开保存，移动和 Ghost 不写入固定棋盘。
4. 出生朝向为横向标准初始朝向，横向居中：I 的 4×4 容器 x=3，其他 3×3 容器 x=3，O 的 2×2 容器 x=4；容器 y=-1。I 初始占第二行，其余形状占顶两行。矩阵、旋转与墙踢候选已在 ALGORITHMS.md 固化为设计数据；后续实现并运行黄金样例。
5. 采用 SRS 的 90°旋转与墙踢规则，I 使用专用旋转中心/补偿表，J/L/S/T/Z 共用相应表；O 旋转不改变占格。数据审查与边界测试是后续实现门槛，不能凭本段宣称已经实现或符合所有官方规则。

旋转与墙踢概念参考官方游戏网站发布的 [Tetris Effect 社区入门指南](https://www.tetriseffect.game/beginners-community-guide/)；该指南不提供本项目完整实现数据。两行隐藏区及其上边界是本项目的空间限制，不保证所有其他版本的顶部墙踢都可执行，需单独测试。

## 二、随机、Next、Ghost 与 Hold

### 2.1 七袋随机

将七种方块各放一份，洗牌后依序取出；用完后生成下一袋。每局重新初始化，测试可注入固定种子随机源。预览只读队列，不额外取随机数；特效和声音不得消费规则随机源。

### 2.2 Next

右侧显示一个下一个方块，标签 NEXT。正常锁定后与空 Hold 后，从队列取新块并更新预览；非空 Hold 交换不消费队列。

### 2.3 Ghost

显示当前形状在保持列和朝向时可下落的最远合法位置，每次移动、旋转和棋盘变化后更新。Ghost 无实体、无碰撞、无音效，硬降应落在同一位置。距离为 0 时不重复绘制，避免叠亮误判。

### 2.4 Hold

1. C 或任一 Shift 暂存。空槽将当前类型存入，并取队列下一块；非空槽交换类型。
2. 换出的块回到出生位置与初始朝向，重置该块重力和锁定计时，不保留原位置或旋转。
3. 每轮只允许一次 Hold；只有当前块锁定后才恢复资格。暂停、换朝向、松开按键都不恢复资格。
4. 换出块若出生碰撞，立即结束。本轮重复 Hold 无效，不消费队列、不播放成功音效。
5. 额外加入轻量 Hold 交换音，作为操作反馈，不引入新玩法。

## 三、键盘与焦点

| 按键 | 动作 | 行为 |
|---|---|---|
| A | 左移 | 单按一格，支持程序控制的长按重复 |
| D | 右移 | 单按一格，支持程序控制的长按重复 |
| W | 软降落 | 立即尝试一格，持续按住按软降节奏推进 |
| Q | 顺时针旋转 | 每次实际按压一次；忽略系统 repeat |
| E | 逆时针旋转 | 每次实际按压一次；忽略系统 repeat |
| Space | 硬降落 | 每次实际按压一次，立即锁定；忽略 repeat |
| C / ShiftLeft / ShiftRight | Hold | C 按下触发；Shift 独立按下再释放触发；同轮资格限制 |
| P / Escape | 暂停或继续 | 非设置状态下适用；忽略 repeat |

使用物理按键 `KeyboardEvent.code`，因此说明指的是常见 QWERTY 键盘上的键位；不另加未要求的快捷键。输入法组合事件不驱动游戏。

- 左右长按：初次立即一步，延迟 150 ms 后每 45 ms 重复一步，不依赖操作系统重复率。
- A/D 同时按住时最后按下者优先；松开优先方向而另一方向仍按住时，立即向另一方向尝试一步并重新计算 150 ms 延迟。
- 离散动作按单调时间戳、同时间戳内的采集顺序处理，不能按绘制帧分批。同一逻辑时刻开始时确定目标活动块代际；若该时刻发生锁定、Hold 或硬降换块，其余旧代际动作不穿透到新块。之后时间戳的新动作可作用于新块，即使两个时刻最终在同一绘制帧内处理。长按 A/D/W 依各自规则时间继续推进。
- 若锁定到期与输入处在完全相同的逻辑时间戳，先处理到期锁定，该时刻指向旧块的动作失效；到期前的有效操作才可刷新延迟。测试需包含到期前、相等、到期后三种情况。
- 上述代际过滤只限制即时方块动作；DOWN/UP 必须更新 held 与未来重复时间，尤其不能丢弃换块同刻的松键信号。同刻新按下可登记后续重复，不立即移动新块。暂停控制项在到期锁定之后、重复/重力之前处理，详见 ARCHITECTURE。
- 只在 RUNNING 且棋盘输入容器拥有焦点时消费游戏动作键并 `preventDefault`，避免空格滚动；不全局禁用页面键盘。
- 原生按钮、滑块和复选框获得焦点时，不消费 A/D/W/Q/E/Space/C/Shift，保留原生行为。Tab 和 Shift+Tab 永远可用；游玩中焦点移出棋盘输入容器（包括进入底栏按钮）先暂停。
- Shift 按下只登记候选，不立即 Hold，也不拦截默认行为。仅在无其他键同时按住、期间未出现任何其他按键且仍处于原游戏焦点时，独立释放 Shift 才触发一次 Hold；组合、双 Shift、失焦、暂停或弹层均取消候选。C 仍在按下时立即触发。
- Ctrl/Meta/Alt 组合交给浏览器；不劫持其快捷键。未来出现的组合键不能靠 Shift 的 keydown 预判，因此采用上条独立释放规则。
- 设置中 Esc 仅关闭设置并回原状态，不同时继续游戏；P 不切换底层状态。没有弹层时，P/Esc 是游玩/暂停状态快捷键，即使焦点在暂停页“继续”按钮也能生效；文字输入/组合输入及浏览器修饰键组合除外。
- 底栏的“暂停”与暂停页“继续”是明确的目标动作，不对当前状态盲目 toggle。一次鼠标操作按按下时的意图执行，focusout 已暂停后随后的“暂停” click 仍保持暂停；按钮不会在这次按压中改成继续动作。设置/重开按钮同样保证一次操作只进入其目标界面。
- 开始、继续与重开后将焦点明确移回棋盘输入容器。失焦、暂停、打开设置、结束和重开均清空已按键集合及 Shift 候选。

## 四、移动、旋转与下落

### 4.1 合法动作

移动或旋转后，所有占格必须在可用区域内，且不与固定格重叠。旋转先检查原地，再按对应墙踢表顺序尝试位置补偿；首个合法候选生效，全部失败则保持原状态。无效动作不刷新锁定时间、不计分、不播放成功音效。

### 4.2 重力与软降

重力间隔见 §六。W 软降间隔 35 ms，与重力共用垂直推进机制，不把重力移动和软降移动叠加执行。按住 W 时成功推进的每一格加 1 分；自然重力、旋转产生的垂直补偿不加软降分。

W 初次按下可立即推进一格并重置垂直计时；松开 W 后重置垂直计时，下一次按正常重力间隔推进，防止同刻连走两格。触地后 W 不重复加分，也不刷新锁定时间。锁定后新块的垂直计时从零开始。

### 4.3 硬降

计算到 Ghost 位置的距离 d，下移 d 格、加 2d 分并立即锁定，不等待锁定延迟。d=0 时不加下降分但仍立即锁定。硬降只处理当前块一次。

### 4.4 锁定延迟

首次触地启动 500 ms 锁定倒计时，允许最后调整。一次成功的左右移动或有效旋转若开始时处于触地状态，可以将倒计时刷新为 500 ms，每块最多 15 次；失败动作及 O 无占格变化的旋转不刷新。由移动或旋转离开支撑时，倒计时暂停但不自动补时，重新触地后继续剩余时间；达到刷新上限后不再补时。计数在整块生命周期内保留，不能通过离地绕过上限。

暂停冻结所有规则计时。重力、W 和硬降不得通过重复触发接触来重建锁定延迟。计时边界需在单元测试中覆盖。

## 五、锁定、消行与顶部失败

一次锁定按以下顺序原子结算：

1. 将当前块写入棋盘，找出所有满行。
2. 记录结算前等级，按本次行数奖励得分；一次性移除满行，其他行保持顺序向下补齐，顶部补空行。
3. 更新累计行数、等级、重力间隔与最高分。
4. 若消行后隐藏生成区仍有固定格，结束；否则从队列生成下一块。新块任一占格与固定格重叠时结束（包括 Hold 换出块）。
5. 未结束时恢复 Hold 资格；提交一次包含锁定、行数、升级和下降距离的事件结果，交给音画层合并处理。

消行动画只用结算前位置快照叠绘，不等待动画再修改棋盘或出块；不暂停规则、不缓存过时玩家指令。局部叠层不能遮住新块。非相邻满行也应同时正确消除。

游戏结束只触发一次，立即停止游戏输入、重力和计分。结果弹层可立即操作，画面淡出与音乐尾音异步结束，不阻塞重开。

## 六、计分、等级与速度

### 6.1 用户指定基础计分

| 行为 | 得分 |
|---|---|
| 消 1 行 | 100 × 结算前等级 |
| 消 2 行 | 300 × 结算前等级 |
| 消 3 行 | 500 × 结算前等级 |
| 消 4 行 | 800 × 结算前等级 |
| 软降 | 成功下移每格 +1 |
| 硬降 | 成功下移每格 +2 |

初始分数 0，初始等级 1。等级 = 1 + floor(累计消行数 / 10)。不引入连击、背靠背、T-Spin 或全清额外得分，避免超出用户计分范围。

跨等级例子：原有 9 行、等级 1，本次消四行加 800，累计变 13 行后升至等级 2；下一次消行才使用等级 2。软降 3 格后硬降 5 格，下降分总计 3+10=13，不对已软降的格子重复奖励。

### 6.2 时间档位为零时的速度基线

以下公式和表格适用于时间档位为 0。提交版还会按有效游玩时间加速，见本文件末尾的试玩反馈规则修订。

自动下落间隔（毫秒）= max(80, round(1000 × 0.82^(等级 − 1)))。

| 等级 | 累计行数门槛 | 自动下落间隔 |
|---|---|---|
| 1 | 0 | 1000 ms |
| 2 | 10 | 820 ms |
| 3 | 20 | 672 ms |
| 5 | 40 | 452 ms |
| 10 | 90 | 168 ms |
| 12 | 110 | 113 ms |
| 13 | 120 | 92 ms |
| 14 及以上 | 130 起 | 80 ms |

等级没有人为上限，速度从 14 级起达到下限；依靠稳定输入和锁定延迟维持可操作性。35 ms 软降始终快于自然下落。曲线先作为可测试基线，真实手感应在可玩阶段评估；调参须记录原因及回归结果。

## 七、游戏状态与界面状态

基础游戏状态为 READY、RUNNING、PAUSED、GAME_OVER；设置、重开确认和标题是界面层状态，不混入规则计算。

| 起点 | 触发 | 终点与行为 |
|---|---|---|
| READY | 点击开始 | RUNNING，新局初始化，尝试解锁音频 |
| RUNNING | P/Esc 或暂停按钮 | PAUSED，冻结规则计时，音乐暂停 |
| PAUSED | P/Esc 或继续按钮 | RUNNING，清空旧输入并重新建立时间基准 |
| RUNNING | 页面隐藏、窗口失焦、焦点移出棋盘输入容器 | PAUSED，不播放失焦暂停提示音，回前台不自动继续；底栏点击按按下时的目标动作处理 |
| RUNNING | 打开设置 | PAUSED＋设置层；关闭回 PAUSED |
| READY / GAME_OVER | 打开设置 | 规则状态不变；关闭返回原界面 |
| RUNNING / PAUSED | 点击重开 | 先暂停，显示局内重开确认；取消保留原局且停在 PAUSED |
| 任意可重开状态 | 确认重开；结束页点击再来一局 | RUNNING，完整清理旧局后初始化 |
| RUNNING | 顶部判定失败 | GAME_OVER，提交最终结果，停止规则 |
| GAME_OVER | 返回标题 | READY，保留最高分与偏好，清理局内资源 |

重开确认用于避免游玩时误触丢失当前局，不用于结束页再次开始。弹层期间只处理弹层输入；底层 P/Esc 不穿透，Esc 仅取消弹层。暂停期间可切换设置，不累加重力、长按重复、锁定或音符进度。

## 八、持久化与重置边界

存储键为 `neon-tetris:v1:preferences` 与 `neon-tetris:v1:best-score`，数据带 schemaVersion=1。保存最高分和六项设置，不保存当前棋盘或续局。

- 最高分初始 0，分数创新纪录时尝试保存，结束时再次确认；显示值至少不低于本局当前分数。
- 读取最高分仅接受非负安全整数，避免 NaN、Infinity、负数与超安全整数；其他数据回退 0。写入异常不终止游戏。
- 偏好字段逐项校验；有效音量数值夹取范围，非法类型回默认。未知版本回默认；不清除其他站点数据。
- 存储访问、JSON 解析与写入都需要捕获异常；存储失败时会话内继续使用内存值，以低干扰文本说明“本次设置/纪录未保存”。
- 重开清空棋盘、活动块、Hold、队列、分数、行数、等级、输入、计时和旧事件；保留设置与最高分，音乐重新从本曲开头开始。
- “新纪录”以本局分数严格超过本局开始时的最高分判断；刷新最高分显示不应让结束页丢失新纪录标记。

## 九、第五阶段开发边界

上述核心规则已实现并自动测试；完整浏览器操作仍待输入/循环/渲染接线。Engine的时间化输入不得补入已结算时间点；暂停冻结剩余时间，若剩余为0，resume本身不移动，下一次逻辑推进才处理到期。具体接口和测试结果见STAGE_05_REPORT。

## 第七阶段接线说明（2026-11-07）

本文规则与core保持不变，现已通过Input/Session/GameLoop接入App。只在RUNNING且棋盘焦点消费操作键；暂停插入时间化PAUSE，冻结墙钟不算入重力/锁定；长停顿>250ms或队列溢出保护暂停，返回前台不自动继续。声音/效果开关不改变规则。消行仍原子结算，旧行光效不等待出块；最高分由App保存、以bestAtStart判断新纪录。规则和接线自动回归通过，真实完整游玩/手感仍待实机，见STAGE_07_REPORT。

## 试玩反馈规则修订（2026-11-07，本轮用户要求＋实现选定参数）

用户要求随时间增强音乐节奏与下落难度，替代此前仅按等级加速。有效游玩时间t取引擎logicalTime（暂停/隐藏不累计，重开归零）。档位=min(4,floor(t/60000))；自然重力间隔=max(80,round(1000×0.82^(level−1)/(1+0.12×档位)))ms。1级0/1/2/3/4分钟为1000/893/806/735/676ms，4分钟封顶；等级仍只由消行提升，计分仍按真实等级，软降35ms与锁定500ms不改变。档位影响下一次排程，已排重力截止不突然提前。音乐节拍对应112/121/130/139/148BPM（四舍五入显示），不改变音高；参数为本轮Agent选定的可测试首版，手感待用户试玩。

课程交付时复核键盘导航。离开棋盘触发的失焦暂停保留新控件的焦点，手动暂停仍可把焦点移至「继续」。实际浏览器用 Shift+Tab 移到设置，再用 Enter 打开，游戏保持暂停。见 [最终验收报告](FINAL_ACCEPTANCE_REPORT.md)。
