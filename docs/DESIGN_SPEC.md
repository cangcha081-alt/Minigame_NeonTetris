# NEON TETRIS · 视觉设计规范与界面规划

版本0.4 · 2026-11-06。当前生效基线为第九节NIGHT SHIFT ARCADE，用户已确认方案A并授权返工。前八节保留旧设计/实现历史，其中旧配色、独立三列网页构图、全局青色强调与菜单通用Glitch由新基线替代。

## 一、艺术指导

### 1.1 核心概念：夜间都市中的电子游戏终端

以深色都市环境中的复古电子仪表盘为整体隐喻。结构清晰、留白克制，界面以细线框、局部霓虹和模块编号形成秩序；故障效果只在信号切换和重要事件中短暂出现。

三层视觉职责：

1. 环境层：深石墨黑与午夜蓝、低对比都市天际线或建筑切线、静态细网格；不加入持续流动的霓虹雨或密集装饰文字。
2. 信息层：清晰的棋盘、HOLD/NEXT、分数与操作提示，稳定对齐，不使用持续 RGB 抖动。
3. 事件层：标题短暂色差、局部横向切片、行内光脉冲、四消与升级奖励。持续时间与优先级见音画规范。

区分普通赛博朋克模板的方式：限制强调色面积；以“城市信号终端”的秩序、线条和排版建立辨识度，不依赖紫蓝大渐变、满屏发光或素材拼贴。

### 1.2 风格边界

不对棋盘做持续透视、桶形变形、强色散或画面撕裂。棋格边缘、Ghost 与固定块始终可读。CRT 扫描线为低对比静态纹理，不做全屏滚动亮条。基础主题不依赖动态效果才能成立。

## 三、字体与排版

1. 标题采用本地几何感回退链Bahnschrift、Arial Narrow、Segoe UI；正文Segoe UI、Microsoft YaHei UI、sans-serif。若需附带专用字体，须选可再分发字体并记录授权，不能让远程字体加载成为可玩前提。
2. 数字采用 Cascadia Mono、Consolas、monospace，启用等宽数字；中文说明使用无衬线字体。
3. NEON TETRIS 标题建议 44～56 px、字重 700、适度字距；副标题 12～14 px，只在品牌区域使用大写与宽字距。
4. 本局分数为最大 HUD 数字，建议 32 px；等级、行数 24 px；区块标题与按钮 14～16 px；中文正文至少 16 px，辅助英文标签至少 12 px。
5. HUD 数字右对齐、不按位数移动面板；超过预设宽度时扩大字段或缩小字号，不截断真实分数，不用 K/M 缩写隐藏计分细节。
6. 所有界面共用 4/8 px 间距基准，面板间隔建议 24 px，内边距 16～24 px；边框通常 1 px，少量直角切口体现终端感。

## 四、主界面布局

桌面采用左侧辅助区、中央棋盘、右侧信息区的三列结构。棋盘视觉与交互优先，侧栏不得挤压棋盘比例。

| 区域 | 内容 | 层级 |
|---|---|---|
| 顶部品牌栏 | NEON TETRIS；副标题；当前状态文字 | 标题为唯一持续品牌焦点 |
| 左侧上部 | HOLD 预览，已使用时标记“本轮已用” | 次级信息 |
| 左侧下部 | 操作说明与设置按钮，完整按键表在原生dialog中弹出 | 按用户意见压缩下方板块，旋转方向写清 |
| 中央 | 10×20 棋盘、Ghost、局部事件层 | 最高优先级 |
| 右侧上部 | NEXT 单块预览 | 明确下一个，不堆队列 |
| 右侧下部 | SCORE、BEST、LEVEL、LINES | SCORE 最大；其余稳定排列 |
| 底部操作栏 | 游玩时暂停、暂停页继续、设置、重新开始；静音/存储状态提示 | 不覆盖棋盘；暂停/继续为明确目标动作，避免焦点变化造成双切换 |

目标桌面视口1366×768；最低设计验收视口960×640。格子按可用高度连续缩放，桌面16～28 CSS px；Canvas按DPR最多2绘制，棋盘保持1:2内容比例。窄屏先棋盘、侧栏下移；不能靠整体缩放到难读来满足布局。实际边界见第八节。

窗口更窄或 200% 缩放时，侧栏重排到棋盘上下并允许页面滚动；不承诺触屏游戏体验。Canvas 内部分辨率按 DPR 缩放并可限制最高倍率以控制成本；CSS 大小与规则网格坐标分离。

## 五、界面状态与文案

| 界面 | 必需内容 | 交互与焦点 |
|---|---|---|
| 标题/开始 | 标题、副标题、开始游戏、设置、最高分、完整按键提示 | 默认焦点在开始；按钮可用 Tab/Enter；不先播放音乐 |
| 游玩 | 棋盘、HOLD、NEXT、SCORE/BEST/LEVEL/LINES、底栏 | 焦点在棋盘输入容器；移到控件先暂停；画面不持续抖动 |
| 暂停 | PAUSED / 已暂停、继续、设置、重新开始 | 棋盘降低亮度但保持可辨；首次焦点在继续；该焦点下 P/Esc 仍可继续 |
| 设置 | 六项控制、当前百分比、返回、保存状态 | 从游戏进入先暂停；Esc 返回；焦点限制在弹层并在关闭时合理恢复 |
| 局内重开确认 | “重新开始将结束当前这一局”、取消、重新开始 | 默认焦点取消；Esc 取消；取消后保持暂停 |
| 游戏结束 | GAME OVER、最终得分/行数/等级、最高分、新纪录标记、再来一局、返回标题、设置 | 淡出期间也可点击；默认焦点再来一局 |

界面以中文动作标签配合必要英文仪表标签，避免只用图标表达设置、暂停或音量。副标题严格保留 CLASSIC GAME · MODERN EXPERIENCE。

## 六、设置面板规划

| 分组 | 控件 | 显示 |
|---|---|---|
| 音乐 | 开关、0～100% 滑块 | 当前百分比；关闭保留数值但停止播放 |
| 音效 | 开关、0～100% 滑块 | 当前百分比；开启或调节时允许短预听 |
| 画面 | 动态效果开关 | 关闭所有装饰性动画，保留必需的方块运动 |
| 画面 | 减少动态效果复选框 | 开启时去除抖动、撕裂、闪光与粒子；总开关关闭时禁用但保留选择 |

设置即时生效并尝试保存，没有额外“应用”按钮。返回不会取消已调整的值。系统减少动态偏好与显式用户覆盖的优先级见音画规范。

## 七、可读性与视觉验收

1. 以实际颜色组合测量文字对比度，正文目标 4.5:1、大号文字目标 3:1；透明叠层后的最终画面仍需检查，token 测量不能替代截图审查。
2. 键盘焦点用稳定青色外框＋间距标记，不只改变文字颜色；控件点击区域建议至少 40×40 px。
3. 不仅通过颜色表达 Hold 不可用、新纪录、暂停或存储失败，同时显示文字。
4. 静态扫描线建议间隔 3～4 px、透明度不超过 0.04，优先放在背景/边框；不能覆盖设置文字而降低可读性。
5. 标题静态色差建议 ±1 px，事件短暂上限 ±3 px；不对 HUD 数字持续复制残影。噪点采用预生成低透明纹理，不逐像素每帧重新计算。
6. 动效关闭时，保留色彩、线条、面板和静态主题；四消/升级仍通过即时文本与分数变化表达。
7. 最终验收应覆盖普通/减少/关闭三种效果、不同DPR、字体回退及窗口缩放；第六阶段已有实际截图审查，但高DPR、200%缩放及完整游玩仍待验证。

## 八、第六阶段实现与验证

2026-11-06：index/styles建立城市终端视觉。背景为缓存SVG静态噪点、网格与局部光晕，左侧几何路线仅作低对比装饰。棋盘机柜采用薄金属边缘、螺钉与磷光刻度，四周留白优先于装饰。七型沿用2.1配色；主体实色、内切面高光、格间深边；Ghost空心低亮，不加RGB偏移。HOLD/NEXT复用格子画法并按实际形状包围盒居中。

READY/PAUSED/GAME_OVER共用棋盘内遮罩，暂停可辨原棋盘，结束显示最终得分/行数/等级和新纪录。升级提示为400ms非阻塞标签。重开确认默认取消；结束页直接再来一局。设置与说明为原生dialog，统一分组线、百分比和焦点框。低高度结束页减少间距并隐藏纯英文装饰脚注，保留全部操作和结果。

标准模式：标题一次短色差、菜单短位移/透明度、hover轻微辉光；没有无限动画和随机抖动。减少模式过渡仅透明度，关闭模式不创建装饰动画，静态主题保留。尚未实现消行/硬降/四消等完整事件反馈，不作已验收承诺。

内置浏览器检查1280×720、1366×768、960×640、390×844：无横向溢出，棋盘完整；七色/活动块/Ghost/Next/Hold样张可辨，设置/帮助可读。960×640结束页实际出现裁切后修正，最终可见内容包围盒落在棋盘范围内。画面由截图工具展示，无截图文件落盘。独立浏览器、字体缺失回退、200%缩放、高DPR及触控未实测。

## 九、视觉返工A/B：当前生效艺术指导

用户否定第六阶段的模板化结果。返工A只读诊断与两个方向方案已在聊天交付，未写文件；现确认A布局并授权实现。游戏名NEON TETRIS保留，主题NIGHT SHIFT ARCADE，主题副标METROPOLITAN ANALOG FUTURISM替换主画面旧宣传副标。

基础色：石墨黑#101416、设备灰#202729、纸白#E2E4DD、磷光青#82D8C5、信号橙#F27A52、黄绿#D8D66B、故障洋红#CE6B9C、电子蓝#6689C5。机身/标签以中性色为主，磷光青只用于读数与交互，橙用于主要操作，洋红用于特殊事件。七型配色可独立出现；S/Z补低饱和派生绿#86B98A与红#C77772，需实际样张验证。

结构：所有区域嵌入同一机身，中央完整10×20显示器、两侧附属显示与独立电子读数窗、下方实体控制台。左右辅助区不填装饰。窄屏把SCORE/LEVEL/LINES和Next/Hold安排在棋盘上方，不能因保持大棋盘而推到首屏外。历史最高分至少有可达的文字入口。

材质：机身哑光吸光，丝印纸白，显示窗发光；仅接合边、凹槽和按钮有方向一致的短阴影。无大面积渐变、玻璃模糊、浮动卡片、城市路线、假年份/在线状态或无功能图标。自有N切线标识与紧密工业字标，不依赖外部字体/图片；正文无衬线，只有数字等宽。扫描线仅Canvas单层低强度。

反馈：机械按钮短行程；数值即时更新后短亮度确认；消行旧格局部收束/消失、硬降至多1px冲击；结束为一次有节奏的局部信号扰动，随后完全稳定。普通设置面板只体现机械开启，不用通用Glitch。各效果有限且有上限，取消/完成移除节点与句柄，重开/暂停/模式切换清理。减少模式无位移/色散/闪光，关闭模式不产生装饰动画。规则即时结算，不等待动画。

范围：输入/持续循环仍留待后续。当前样张只验证事件表现，不代表真实整局通过；原创音乐仍属音频阶段，不用静态音量控件冒充已播放。

## 十、2026-11-07 UI精修覆盖（当前实现）

本节细化第九节，旧第八节持续色差/路线等记为历史。桌面为850px以内同一设备壳体，顶部纸白NEON TETRIS铭牌＋主题/状态灯＋帮助/设置；左侧SCORE/LEVEL/LINES/HIGH SCORE独立仪表，中部最大10×20内凹CRT，右侧NEXT/HOLD附属屏，下部折叠印刷键位及机械控制。移动四项仪表全部保留，Next/Hold并排，棋盘完整，控制台允许纵向滚动，不为同屏缩到不可读。

保留八色及七型派生色token、系统Display/数字等宽/无衬线正文。黑灰壳体与纸白铭牌主导，不增加图片/外部字体/图标；接合线、刻度和短阴影表达材质。棋盘局部约3.5%纸白玻璃反光、边缘暗角；Canvas扫描线不重复叠加。七型实色＋内高光/底侧暗边，Ghost轮廓alpha .78，不作通道偏移。

数值即时更新后有限确认，无跳动；按压2px，减少/关闭模式无按压位移。消行弱高亮到单向扫描140ms、四消180ms，滚动一秒亮度反馈最多2次；暂停局部裁切140ms，结束420ms一次信号扰动后稳定，普通菜单仍局部显现而非RGB故障，标题印刷稳定。低强度且棋盘局部优先，避免全屏闪光。资源有界并在清理/模式切换后回收。

主Agent实际检查1366×1000、960×640、390×844，保存6张截图，79项测试通过。细节、12项自评及未测范围见UI_REFINEMENT_2026_11_07.md。短屏底部滚动是当前取舍；艺术效果未获用户最终确认。
