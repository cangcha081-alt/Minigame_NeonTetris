## 代码质量与功能完整性

**职责划分合理。** Engine 决定规则与时间，Session 管队列和暂停，GameLoop 独占 rAF，Renderer 只读快照，Audio 和 Effects 消费有序事件，UI 和 Storage 分别负责交互和持久化。检查了 28 个源码模块、49 条相对导入，未发现循环或缺失引用。模块与事件名可追溯到其职责。组合式工厂适合当前规模。AudioManager 生命周期分支最多，新增的统一失败出口比继续各处捕获更容易验证。PCM 诊断中的包络复写是值得跟踪的重复。

**主要功能完整。** 整套覆盖 7-Bag、墙踢、堆叠碰撞、锁定、单至四消、计分、升级、Ghost、Hold、顶部失败与重开。专项用例另覆盖最高合法位置旋转、全候选被挡时无变化、200 组密集近顶盘面、非法状态命令、存储损坏和配额异常。确定性四消跨级只提交一次消行与升级事件。键盘映射、长按和跨帧率同输入轨迹已有回归。

**资源管理通过已测场景。** 100 次真实 App 会话重开在测试替身中复用一个 Context，最多一个音乐调度器及一个待执行帧。暂停及隐藏停止推进，显式恢复才继续。重开、切换动效模式和销毁会清理动画及通知计时器。App、Input、Settings 与 UI 监听均有对应清理，生产入口的页面生命周期监听随文档存续。浏览器长时内存曲线尚未采样。

## 玩家体验、视觉与可访问性

- **上手与状态**。开始按钮的键盘焦点清晰，机身说明和帮助页把所有键列全。独立 SCORE、LEVEL、LINES 和 HIGH SCORE 有稳定位置，暂停与结束有明确字样，结束另提供本局成绩。A/D、Q/E 对熟悉方向键的玩家需要适应。已有按键时序测试支持响应一致性。手感与一分钟档位变化仍需普通浏览器长局评估。
- **Urban Retrofuturism**。机台有纸白铭牌、深色内凹 CRT、独立仪表与实体控制键。背景旧屏幕和模拟介质提供环境色，机壳自身的颜色收得住。主棋盘比两侧预览明显更大，组合有一致的工业设备语言。桌面图中左侧背景仍稍抢视线，但不会掩盖棋盘或读数。
- **Glitch Art、Chromatic Aberration**。结束态才有一次 420ms 信号扰动，位移约 ±1px，色差会收回。暂停采用短裁切，得分与硬降用不同反馈。常态的故障艺术存在感较弱，色差是短促的次要语言。棋盘和方块没有持续 RGB 残影。
- **CRT、字体与色彩**。2% 静态扫描线、局部反光与内凹边框营造 CRT 层次，七色样张的格界与 Ghost 轮廓可见。工业铭牌、等宽读数、粗体状态字和常规中文正文有层次。抽测实色组合对比度分别为机身正文 11.83:1、次要正文 6.83:1、得分 11.09:1、开始按钮 6.78:1。正文配色满足项目 4.5:1 目标，透明叠层和特殊显示模式需分别评估。
- **动画与操作**。反馈层设为 `pointer-events: none`，规则先结算并允许新块继续接收输入。标准模式的行光 140–180ms、硬降 80ms，四消粒子最多 16 个，得分浮字最长 450ms。中央浮字会短暂覆盖一小块棋盘，密集堆叠时值得观察。行光每滚动一秒最多两次，结束遮罩单调变暗。关闭不创建装饰动画，减少模式保留文字、去掉飞散与扫描。还需录屏检查连续事件下的实际亮度、面积与可读性。
- **实查范围**。1366×900、390×844 和 320×568 没有横向内容溢出。通过键盘打开设置并切换减少、关闭，刷新后关闭与减少偏好均保留。测试后把内置预览恢复为标准动效，减少偏好已显式设为关闭。系统偏好跟随和监听释放由独立用例覆盖。

## 音乐与音效

112 BPM 的 16 小节循环以方波、三角波和电子节拍组织。谱面设计与夜班街机题材相容。移动/软降刻意弱化，硬降和锁定节奏不同，四消使用独立奖励音型，升级音错峰。限频、最多八个事件声部及事务仲裁降低重叠风险。音乐和音效默认增益分别为 35% 和 55%，双总线音量、静音、失败重试、重复开始和暂停/结束停止均有自动化证据。实际混音平衡、音色统一度和四消奖励感需要试听判定。

内置 Chromium 的 AudioContext 在开始手势后进入 `running`，读到一次 `GAME_START`，保护性暂停后音乐调度归零。浏览器实际离线渲染两轮和叠加声效的 22,050 Hz 单声道信号，长度 69.57 秒，峰值 0.35616，RMS 0.02324，削波样本 0。接缝前后 20ms RMS 为 0 / 0.04377。谱面最后包络比循环结束早约 107ms，有一段明确的休止。离线验收页使用与播放器同源的谱面与声效预设，另建音频图。实时设备输出、节奏切换后的接缝和主观听感需单独复核。

1. **普通浏览器长局**。运行 `npm.cmd run dev`，打开本地 5173 端口，用键盘开始，试玩至少 75 秒并穿过 60 秒加速点。交替使用 A/D、Q/E、W/Space 和 Hold，中途切标签页并主动继续。观察输入、落速、暂停期间棋盘和恢复后的连续性。
2. **耳机试听**。先用默认 35%/55%，连续听两轮，再分别调节、关闭两条总线。听 34.29 秒附近的接缝、暂停恢复和游戏结束尾音。打开整合验收页，分别选“四消升级初局”和“结束前初局”，开始后按 Space。比较四消与升级是否有层次、是否盖过背景音乐，以及结束是否自然收尾。
3. **可访问性和动画**。以 320×568 和 390×844 各试一次，使用 Tab/Shift+Tab、Enter 和 Esc 打开设置及返回。切换系统减少动效和游戏内关闭，录屏检查四消后新块、浮字覆盖与亮度。用色弱模拟和屏幕阅读器分别确认相近方块与状态信息。
