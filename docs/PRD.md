## 一、产品定位

NEON TETRIS 是面向普通桌面浏览器的单人经典俄罗斯方块。副标题为 CLASSIC GAME · MODERN EXPERIENCE。

核心价值是稳定、清晰、有节奏感的经典玩法，以及彼此统一的都市电子仪表盘视觉、原创复古电子音乐、操作音效和事件反馈。艺术表现服务于操作与成就感，不持续扭曲棋盘，不以装饰掩盖游戏状态。

目标用户是使用键盘的休闲玩家和课程评审人员。主要场景为本地启动后进行数分钟至较长时间的连续游玩、暂停调节设置、结束后重开，以及展示课程开发与验证过程。

## 二、目标与边界

### 2.1 用户要求

1. 保留完整经典玩法，提供 Next、Ghost、Hold、得分、行数、等级和最高分。
2. 将 Urban Retrofuturism、Glitch Art、Chromatic Aberration 与 CRT 元素形成统一设计语言。
3. 提供原创循环音乐、完整事件音效、动态反馈及可持久化的设置。
4. 在普通桌面浏览器运行，尽量减少第三方依赖。
5. 保留人机协作与项目记忆资料，支持分析 Agent 的能力、局限与上下文恢复。

### 2.2 明确不做

不增加地域关卡、地图解锁、复杂任务、道具、Boss、多人联机和复杂成就系统。本版也不规划账号、云端排行、付费、触屏操作、游戏存档续局、T-Spin 或连击额外计分、180°旋转和按键自定义。

### 2.3 产品成功标准

- 能独立完成开始、游玩、暂停、设置、失败和重开的完整循环。
- 核心规则有可重复的自动测试；浏览器验证覆盖输入、音频、持久化和全部状态。
- 棋盘始终可辨识，减少动态效果和关闭动态效果均能完整游玩。
- 重开、暂停和设置往返不产生重复循环、重复声音或残留按键。
- 无第三方运行时依赖为推荐目标；若引入开发依赖，必须说明收益。

## 四、体验流程

1. 首次进入：展示标题、副标题、开始按钮、设置入口、最高分与完整键位说明。不自动播放音乐。
2. 点击开始：建立本局状态，出首块，启用棋盘输入；在用户手势中尝试启用音频。
3. 游玩：中央棋盘，左侧 Hold 与操作提示，右侧 Next 和统计；底部提供暂停、设置和重开按钮。
4. 暂停：停止规则时间，保留画面与统计；可继续、设置或重开。音乐暂停；设置可预览音量。
5. 设置：从游玩进入时先暂停。关闭设置回到暂停页，必须主动继续；从标题或结束页进入时返回原页。
6. 结束：保留最终棋盘作为背景，显示本局得分、行数、等级、最高分及新纪录标记；提供再次开始与返回标题。
7. 重开：新一局重置全部局内状态，保留最高分和偏好，不刷新网页。

## 五、需求冲突与建议处理

| 问题 | 建议方案 | 原因 |
|---|---|---|
| W 软降、Q 顺时针、E 逆时针与常见键位习惯不同 | 严格保留用户键位；在标题和侧栏持续展示 | 用户明确指定，不静默换键 |
| “经典”未限定旋转、随机与锁定细则 | 七袋随机；90°旋转及墙踢；500 ms 锁定延迟、最多 15 次刷新 | 减少长时间缺块与落地操作挫折；细则见规则文档 |
| 跨等级消行用哪个等级计分 | 本次消行采用结算前等级，再更新总行数和新等级 | 避免同次事件计分歧义 |
| 消行动画可能阻塞操作 | 规则立即结算并出下一块，旧行快照做不超过 180 ms 的局部叠层 | 不为特效添加输入冻结 |
| 音频自动播放要求与浏览器限制 | 在开始操作中启用音频；失败不阻塞游戏，给出非模态声音启用提示 | 不承诺无交互自动播放 |
| “动态效果关闭”与“减少动态效果”重叠 | 关闭优先；减少模式仅保留低幅度短渐变；静态主题仍保留 | 六项设置行为可预测 |
| 暂停、设置与键盘默认行为冲突 | 规则输入只在棋盘游玩焦点生效；表单保留原生键盘；Tab 不拦截 | 防止设置时移动方块或破坏按钮操作 |
| 硬降、固定、消行与升级可能同时播放 | 按事件优先级裁剪、错峰，四消奖励最突出 | 防止噪声和过度特效 |

## 七、非功能要求

1. 兼容性：计划验收时的稳定版 Edge、Chrome、Firefox 桌面浏览器；当前只确认本机存在 Edge，另外两者可用性待验收阶段核实。
2. 性能：以当前机器 Edge、1366×768、标准动效、60 Hz 显示条件为首轮基线，目标单帧主线程更新与绘制工作量 P95 ≤16 ms，稳态无连续多帧超过 50 ms 的卡顿；不将显示器刷新率误当代码耗时。实测硬件、DPR、浏览器和工具必须记录，当前未测。
3. 规则一致性：同一随机源及时间化输入序列，在不同绘制频率下得到相同规则结果；暂停不追赶后台时间。至少比较 60/144 Hz 绘制下的“硬降、稍后旋转”序列，不能以帧批次丢弃稍后动作；同刻锁定到期先于旧块输入，见规则文档。
4. 容错：存储或音频不可用不阻塞游戏；不加载外部 CDN 字体、脚本或音乐作为首版前提。
5. 可读性：正文与背景对比度目标 ≥4.5:1，大号文字目标 ≥3:1；不能仅用颜色表示暂停、奖励或警告。
6. 动效：遵循本项目更保守的局部单峰反馈与频率约束，不以“低于三次”替代实际闪光、亮度和面积检查。
7. 资源：音乐原创合成；如后续加入外部素材，记录作者、来源、许可证和所需署名。
